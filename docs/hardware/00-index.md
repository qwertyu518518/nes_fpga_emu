# EP4CE10 开拓者板硬件学习文档

> 面向熟悉嵌入式 C、只学过基础 Verilog 的读者。本文是面向 NES/FC FPGA 项目的板级学习路线，不是可直接复制的 RTL 实现，也不替代芯片数据手册、原理图和时序报告。

## 1. 文档目标

本目录把“能在仿真中工作的数字逻辑”连接到“能在 EP4CE10 开拓者板上工作的系统”。重点放在四件事：

1. 看懂板级事实：器件、时钟、存储器、外设和引脚。
2. 理解数字电路和 Verilog 中最容易造成隐性错误的时序问题。
3. 建立 50 MHz 板级时钟与 NES、VGA、TF、SDRAM、WM8978 之间的时钟域和数据通路。
4. 用分阶段的 P0 板级实验，把“例程能编译”推进到“接口在真实板上可验收”。

本套文档只讨论架构、约束、接口协议、验证方法和风险。实际 RTL 应由项目后续实现，本文不提供实际 RTL。

## 2. 证据等级和阅读约定

全文使用以下标记：

- **【已确认事实】**：来自本项目已核验信息、板卡约束文件、器件/工程报告，或多个来源相互印证的事实。
- **【厂商例程观察】**：从正点原子 `4_SourceCode.rar` 中读到的例程结构、参数、接口假设或报告数字；它说明“例程如何做”，不等于所有板卡、所有卡或所有时序都天然正确。
- **【待上板验证】**：必须用实际 FPGA 板、显示器、TF 卡、SDRAM 芯片、WM8978 模块、示波器/逻辑分析仪或软件观察确认的事项。
- **【风险提示】**：在当前器件资源、时钟约束、引脚复用或协议边界下，可能导致仿真通过但板上失败的事项。

阅读时先看每章末尾的“本章结论”和“验证清单”。如果结论与现场测量冲突，以测量结果和对应芯片数据手册为准，并回写验证记录。

## 4. 一张图建立全局认识

可以把目标系统分成以下层次：

```text
                 50 MHz 板载时钟
                       |
                 PLL / 复位分发
        +---------+--------+---------+---------+
        |         |        |         |         |
    NES CPU/PPU  VGA     TF SPI   SDRAM      WM8978
     21.48/5.37  25 MHz   慢速/正常  100 MHz    12 MHz MCLK
        |         |        |         |         |
    NES RAM/总线  帧缓存   扇区/FAT  行/列/刷新  BCLK/LRC/数据
        |         |        |         |         |
        +---------+--------+---------+---------+
                         |
                 4 按键 / 扩展输入
```

这不是要求所有模块共享一个时钟，而是要求每个跨域边界都有明确的握手、FIFO 或时序余量。VGA、TF、SDRAM、音频各自有自己的节奏；NES 核心也不应被 VGA 像素时钟直接驱动。

## 6. 三个必须先建立的观念

### 6.1 硬件不是“执行语句的 CPU”

C 语句通常一次执行完；硬件逻辑在一个时钟沿同时观察所有输入，并在寄存器中保存状态。一个组合表达式不是循环，除非综合器明确推断出硬件结构。一个计数器的“延迟”由位宽和时钟频率决定，而不是由软件执行时间决定。

### 6.2 同一个信号不代表同一个时序

一个名为 `ready` 的信号若在 50 MHz 域产生、在 100 MHz 域使用，即使逻辑值为 0/1，也可能在一个周期内出现亚稳态或采样不一致。先问“它在哪个时钟域产生、由谁采样、允许等待多久”，再讨论功能。

### 6.3 例程成功不是接口规格

例程可以证明某个作者在某个板卡版本、某个器件和某个外设上曾经让工程编译或工作；它不能自动证明容量、时序、电气电平、FAT 边界、音频采样率或长期稳定性。文档中凡涉及这些内容，均单独标记为观察或待验证。

## 8. 本目录不承诺的事情

- 不承诺某一 TF 卡都能在所有 SPI 模式、电压和 FAT 类型下工作。
- 不承诺仅凭例程就能确定 SDRAM 芯片的完整容量或所有 AC 参数。
- 不承诺 RGB LCD 的 `lcd_id` 编码适用于所有兼容屏。
- 不承诺只靠约束文件解决 I/O 时序；外部器件的建立/保持时间仍需测量。
- 不把正点原子的版权例程直接复制进本项目；例程只作为观察材料。

## 9. 每完成一章应能回答的问题

- 这个信号由哪个时钟域产生？由哪个时钟域采样？
- 这个接口的位宽、字节序和有效标志是什么？
- 复位期间外部器件是否会被错误地看见为“空闲”？
- 读存储器、FIFO 或外部总线需要等待几个周期？
- 出错时是停止时钟、拉低片选、进入错误状态，还是让上游重试？
- 结论来自原理图/数据手册、例程观察，还是还没有上板证据？

具备这些问题的答案，才算真正开始理解 NES FPGA 板级系统。
